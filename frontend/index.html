Insight 1: The Accuracy Paradox

The Majority Baseline scores 99.83% accuracy simply by guessing legitimate every time. Yet, its fraud detection rate (recall) is 0%, demonstrating that accuracy is a misleading metric for severe imbalance.

Insight 2: NumPy Scratch Parity

The Custom Scratch model achieves 0.9752 ROC-AUC, exceeding Scikit-Learn (0.9721) while reducing false positives from 1,386 down to 1,242 using analytical gradient descent.

Insight 3: The Power of Threshold Tuning

Tuning the cutoff from τ = 0.50 to τ* = 0.95 slashes false alarms from 1,242 to 93 (a 92.5% reduction) while preserving 86.7% recall, lifting F1 from 0.126 to 0.616.

Theory & Derivations

Mathematical Foundations & College Viva Guide

01

The Sigmoid Hypothesis

Maps linear combination to probability space $P(y=1|x) \in (0, 1)$:

σ(z) = 1 / (1 + e-z)
z = wTx + b

We implement clipping $\text{clip}(z, -250, 250)$ in pure NumPy to prevent floating point overflow in np.exp(-z).

02

Weighted Binary Cross-Entropy

Overcomes 99.83% class dominance with inverse frequency sample weights:

J(w, b) = - (1 / Σwi) Σ wi [ yi ln(ŷi) + (1 - yi) ln(1 - ŷi) ] + (λ / 2) ||w||2

Fraud instances receive ~289× higher weight penalty for misclassification.

03

Analytical Gradient Descent

Derivatives of weighted BCE loss with L2 regularization:

∂J / ∂w = (1 / Wtot) XT (wi × (ŷ - y)) + λ w
∂J / ∂b = (1 / Wtot) Σ [ wi × (ŷi - yi) ]

Weights update iteratively: w ← w - α ∂J/∂w.
